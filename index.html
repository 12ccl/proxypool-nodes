Clash 订阅转换

AIsouler/MyClash 覆写脚本 → 可直接导入的静态配置
＋
点击选择文件，或拖到这里
任意 .yaml .yml .txt .json .conf，可多选合并
① 生成配置：订阅 / 节点链接 → 用 MyClash 覆写脚本生成完整配置
② 体检修复：已有一份配置（任何来源）→ 只修问题，不改分流结构
③ 重构分组：把分组改成「节点选择 → 自动选择 / 各地区（含地区自动）/ 手动切换 / 全球直连」
④ 导出链接：把配置反着转回一行一个节点链接（vless/vmess/trojan/ss/hysteria2/tuic/anytls），给 v2rayN、v2rayNG、NekoBox、Shadowrocket 用
⑤ Surge / Shadowrocket / Loon：生成 .conf（同一套 Surge 语法），各自「从文件导入」即可
⑥ 中转链：把连不上的节点挂到「🛰 中转入口」后面（dialer-proxy）；自动跳过「共享域名+高位端口」的国内入口型节点（这类经境外桥会 503）
高级选项
手机上怎么用
1. 点上传区选文件（或粘贴订阅链接）→ 开始转换 → 保存到手机
  · 支持的系统会弹出保存框，自选文件夹和文件名
  · 其余会弹出系统分享面板：选「保存到文件」挑路径，或直接分享给 Clash 客户端
  · 都不支持时进浏览器默认下载目录（下载/Download）
2. 打开 Clash 客户端（Clash Verge / Mihomo Party / FlClash / ClashMetaForAndroid）→ 配置 → 从文件导入

能传什么
· 机场导出的 Clash 配置（.yaml / .yml）
· 机场导出的订阅文本（.txt，base64 也行）
· 节点链接列表（ss / vmess / trojan / vless / hysteria2 / tuic）
· 一次选多个文件会合并节点，重名自动加后缀

链接下载失败？ 机场多半没开跨域，改用上传文件。

小米 / 华为 / QQ / UC 浏览器
· 若选文件时看不到 .yaml，在文件选择器里点「浏览 / 其他文件」而不是「图片 / 视频」；
· 若页面点了没反应，关掉浏览器的「云加速 / 极速模式 / 无图模式」再刷新；
· 仍然不行就直接用页面里的「粘贴配置内容」，或换 Chrome / Edge。

转换会自检：规则引用的策略组 / 规则集 / 节点必须存在，否则直接报错，不会给你一个导入就崩的配置。

体检修复能修什么
· udp: false → 开启（QUIC 泄漏、语音游戏连不上）
· 废弃字段 global-client-fingerprint → 移除
· DNS 缺 enhanced-mode → 补 fake-ip
· REALITY short-id 被读成数字 → 强制加引号
· 数值型密码 / uuid 被读成数字 → 强制加引号
· 非法 tun.stack（mips 等）→ mixed
· 策略组 / 规则指向不存在的节点或组 → 删除或改到默认组
· 空策略组、重复节点名、缺 mixed-port → 补齐
